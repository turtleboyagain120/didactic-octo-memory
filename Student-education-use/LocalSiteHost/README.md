Local Site Host 🏠🌐
PC-hosted proxy for any website (like coolmathgames.com locally). Enter URL, view via proxy. Licensed for school/education.

8 Steps to Run (For Others) 📋
1. Download: git clone https://github.com/turtlebot12/Student-education-use (or extract ZIP).
2. Open Terminal: cd LocalSiteHost (or school_proxy).
3. Check Python: python --version (3+ required).
4. python server.py
5. Open Browser: http://localhost:8000
6. Enter URL: e.g. https://coolmathgames.com → proxy loads.
7. Browse safely!
8. Stop: Ctrl+C.
